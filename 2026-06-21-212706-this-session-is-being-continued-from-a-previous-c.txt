  hitung ulang totalStock; tambah inventorySnapshot; commission pakai ID
  deterministik (commissions/{orderId}), simpan commissionId di order

  inventoryRecoveryFailed: true (bukan throw, bukan skip diam-diam); gunakan
  commissionId untuk delete commission tanpa query (dengan fallback query untuk
  order lama)

  read-modify-write)

  order sebelumnya completed, sekarang akan trigger revert stock (sebelumnya
  hanya update status). Ini fix bug pre-existing, bukan regression.

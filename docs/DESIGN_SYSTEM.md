# Design System & Visual Identity

## Aesthetic Principles
- **Luxury Minimalist:** Clean layouts, generous white space, and high-quality imagery.
- **Action-Oriented:** Clear Call-to-Actions (CTAs) using the brand's accent color.
- **Responsive:** Optimized for mobile riders who often check products on-the-go.

## Color Palette
Defined in `app/globals.css`:
- **Main Accent:** `#F59E0B` (Amber/Gold) - Used for primary buttons, active links, and highlights.
- **Secondary Text:** `#374151` - For body text and descriptions.
- **Primary Text:** `#111827` - For headings and titles.
- **Background:** `#F9FAFB` (Subtle Grey) - Main page background.
- **Surface:** `#FFFFFF` - Component cards and sections.

## Typography
- **Primary Font:** `Inter` (Sans-serif).
- **Hero Headings:** Large, bold, uppercase, with high letter-spacing.
- **Eyebrows:** Very small (11px), bold, tracked out (0.2em), uppercase, usually in accent color.

## Components Style
- **Buttons:**
    - `btn-primary`: Background accent, white text, subtle shadow.
    - `btn-ghost`: Bordered, clean, for secondary actions.
    - `btn-wa`: Green/Accent variations for WhatsApp interaction.
- **Cards:** Border radius 8px, `border-light` (#E5E7EB), subtle hover lift (`translateY(-4px)`).
- **Inputs:** Clean borders, focus states with accent color glows.

## Layout Specs
- **Container:** Max-width 1280px.
- **Spacing:** Standardized padding for sections (48px to 72px vertical).
- **Grid:** Responsive grids (1 col mobile, 2-4 cols desktop).

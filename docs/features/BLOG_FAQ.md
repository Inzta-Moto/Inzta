# Content Modules: Blog, FAQ, & Testimonials

## Blog System
- **Purpose:** Lifestyle branding, SEO, and rider guides.
- **Structure:**
    - `Article`: Title, Slug, Excerpt, Content, ImageUrl, Author, Date.
- **Frontend:**
    - Home Page: Scrollable horizontal grid on mobile, 3-column grid on desktop.
    - Blog List: Paginated or infinite scroll grid.
    - Blog Detail: Clean reading experience with support for embedded images.

## FAQ Module
- **Purpose:** Handling common objections (Waterproofness, Installation, Shipping).
- **Structure:** `Question`, `Answer`, `Order`.
- **UI:** Accordion-style interaction with smooth height transitions.

## Testimonials (Social Proof)
- **Purpose:** Building trust with real rider reviews.
- **Structure:** `Author`, `Text`, `Role`, `Avatar`.
- **UI:** Center-snapped horizontal scroll on mobile for better engagement.

## Content Gallery
- **Purpose:** Displaying the product in real-world scenarios.
- **UI:** Infinite or large grid with Lightbox zoom.
